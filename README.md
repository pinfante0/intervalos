# Intervalia

**Intervalia** es un juego web de entrenamiento auditivo para reconocer intervalos
melódicos. Se creó para la asignatura *Educación Musical y su Didáctica* de la
Universidad de Jaén, pero puede utilizarse en otros contextos educativos o simplemente
como entretenimiento.

**Jugar:** <https://pinfante0.github.io/intervalos/>

No requiere instalación ni registro: funciona desde el navegador, también en móvil.

## Cómo se juega

En cada turno suenan dos notas de piano consecutivas. Hay que identificar el intervalo
melódico y pulsar su nombre en la cuadrícula de respuestas. Si la respuesta no es
correcta, el juego muestra y permite comparar el salto que sonaba con el que se ha
elegido.

El juego trabaja los doce intervalos simples —de segunda menor a octava justa—, tanto
ascendentes como descendentes. Incluye canciones de referencia cuando están disponibles
como ayuda para reconocer algunos saltos.

## Modos

- **Práctica:** permite elegir los intervalos y la dirección que se quieren trabajar. Da
  más presencia a los que cuestan más y ofrece pistas durante el turno.
- **Reto:** propone una progresión de siete niveles. Cada nivel tiene diez turnos y se
  supera con al menos ocho aciertos.
- **Contrarreloj:** un minuto para responder tantos turnos como sea posible.
- **Concurso (en el aula):** pensado para proyectar y jugar por equipos; el profesorado
  registra las respuestas de la clase.

## Progresión

Los niveles recorren las familias de intervalos de forma gradual: justos y octava;
terceras y sextas; segundas y séptimas; tritono; los doce intervalos ascendentes; los
doce descendentes; y, por último, un formato que combina los doce en ambas direcciones.

## Privacidad y accesibilidad

Intervalia no recopila datos personales ni utiliza cuentas. El progreso, el volumen y el
tema elegido se guardan únicamente en el almacenamiento local del navegador del propio
dispositivo. Si se borra ese almacenamiento o se cambia de navegador o dispositivo, el
progreso no se transfiere.

El juego ofrece tema claro, oscuro o el del sistema, y respeta la preferencia del sistema
para reducir el movimiento.
